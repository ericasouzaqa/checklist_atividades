# ✅ Checklist Diário

Aplicação desktop desenvolvida para organização diária de tarefas, acompanhamento de produtividade e gerenciamento de atividades.

## 🎬 Demonstração

<img width="1898" height="938" alt="demo" src="https://github.com/user-attachments/assets/a3fd01c0-bb5c-4f81-b267-c09cde6e3533" />



## ✨ Recursos

- Checklist diário por data
- Histórico de atividades
- Drag and Drop
- Lixeira com restauração
- Movimentação de tarefas entre datas
- Temas personalizados
- Exportação CSV
- Exportação XLSX
- Backup automático
- Funcionamento offline

## 🚀 Diferenciais

- Janela fixável sobre outras aplicações
- Histórico completo por data
- Recuperação de tarefas excluídas
- Organização visual personalizável
- Dados armazenados localmente

## 💻 Tecnologias

- Electron
- JavaScript
- HTML
- CSS
- SheetJS (xlsx)
